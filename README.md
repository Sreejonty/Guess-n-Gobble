# Guess-n-Gobble
A meal service like Food Panda or Uber Eats but make it mysterious. 
--npm install (you just need to install this on your cmd of windows and nothing else acc to chatgpt but if you still need to the followings are given)
Run dev server -
npm run dev
Open in browser
Copy the local URL (something like http://localhost:5173/) and open it in your browser.

how to download the necessary packages (i think you need these)
- VS Code extensions (optional but helpful):
ES7+ React/Redux/React-Native snippets
Tailwind CSS IntelliSense
Prettier (for formatting)

-install node.js
Go to Node.js official site.
Download the LTS (Recommended) version (e.g. v18.x).
Run the installer (.msi on Windows / .pkg on Mac).
Keep the default options checked (like installing npm along with Node).
After install, verify it worked:
node -v
npm -v
(if it doesn't work which in my case it doesnt, check yt how to install node js)

-Install Tailwind CSS (if not already installed)
npm install -D tailwindcss postcss autoprefixer
npx tailwindcss init -p
